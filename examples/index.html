agenticschema

Turn the Schema.org markup a page already has into MCP tools an AI agent can call. Both pages below run against the packages published on npm, not a local build.

A product page carrying the script tag. Open it with an agent attached and the tools are callable. Open it without one and the console says so, rather than looking fine.
